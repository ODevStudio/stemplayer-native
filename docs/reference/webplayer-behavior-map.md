## Browser Details Excluded

AudioWorklet, Web Audio, SharedArrayBuffer, WebCodecs, IndexedDB, browser workers, DOM events, Vite, Playwright, and browser isolation headers are not native requirements. Their purposes are represented above as real-time output, bounded shared state, native decoding, versioned peak caching, background work, input events, and qualification evidence.

## Known Reference Limitations

- The webplayer reports JS heap proxies, not trustworthy whole-process native memory.
- Browser hidden-tab lifecycle remained a manual limitation.
- No independent private `.stem.mp4` or real separator WAV bundle was available in the recorded M8 matrix.
- HLS uses a patched upstream scheduler; the native design must specify grouped buffering directly rather than inherit that implementation.
