# Initial Risk Register

| ID | Risk | Likelihood / impact | Mitigation | Owner | Exit evidence |
| --- | --- | --- | --- | --- | --- |
| R1 | Symphonia AAC/ALAC or MP4 edit behavior is not exact enough. | Medium / critical | Keep exact timeline mapping outside decoder; qualify frame count, complete/seek hash, edits, packet boundaries, and soak before adoption. | Audio owner, unnamed | Public codec vectors on all targets. |
| R2 | Slint idle footprint or accessibility misses a release platform. | Medium / high | Keep engine UI-independent; qualify Windows before Phase 2; qualify optional macOS/Linux expansions in Phase 12 before publishing those platforms. | Product owner, unnamed | Windows resource and accessibility reports; optional platform reports before publication. |
| R3 | Linux device/backend fragmentation causes failures or excess latency. | High / high | Keep Linux unsupported by default; optional Phase 12 expansion must test PipeWire, PulseAudio, ALSA, priority denial, and the declared distribution matrix. | Release owner, unnamed | Optional Ubuntu/Fedora device matrix and suspend/change tests before Linux publication. |
| R4 | Audio callback allocates, blocks, or touches unbounded state. | Medium / critical | Callback copies prepared stereo only; preallocate; SPSC; allocation/lock instrumentation and stress tests. | Audio owner, unnamed | Callback audit and zero-allocation test. |
| R5 | Role/path/URL ambiguity opens unintended resources. | Medium / critical | Normalize once, reject ambiguity/traversal/schemes/redirects, explicit source selection, adversarial corpus. | Security owner, unnamed | Public hostile input suite. |
| R6 | Private fixtures conceal structural gaps or leak metadata. | Medium / high | Public synthetic coverage is mandatory; aliases/hashes only; artifact privacy scan. | Security owner, unnamed | Fixture manifest and scan results. |
| R7 | Transitive unsafe or license obligations are missed. | Medium / high | Lock dependencies, inventory licenses, deny handwritten unsafe code, audit advisories without blanket ignores, and review callback-facing crates. | Release/security owner, unnamed | Dependency audit, license inventory, and documented exceptions. |
| R8 | Renderer/GPU allocations defeat the 50 MiB idle budget. | Medium / high | Measure process set and GPU allocations; software fallback; avoid Skia; replace toolkit if necessary. | UI owner, unnamed | Raw per-renderer reports. |
| R9 | HLS buffering loses group synchronization or grows with duration. | Medium / critical | Group-level bounded queues, common publication, declared preroll trim, hostile server tests, eight-hour soak. | Audio/network owner, unnamed | Zero-offset, bounded-memory HLS report. |
| R10 | Device-rate conversion adds drift or callback work. | Medium / high | Resample final stereo on render worker; fixed source timeline; small output ring; exact ratio/end tests. | Audio owner, unnamed | 44.1/48/96 kHz device matrix. |
| R11 | Native macOS or Linux runtime evidence is unavailable. | High / medium | Treat those targets as optional Phase 12 expansions; cross-compilation never qualifies native audio, rendering, or accessibility. | Release owner, unnamed | Native optional-platform report or explicit unsupported/unpublished designation. |
| R12 | Temporary monorepo location silently couples native and web builds. | Low / critical | Copy-only standalone verification, dependency scan, separate repository before production phases. | Release owner, unnamed | Standalone build with webplayer absent. |

Open risks require named owners before the phase that implements or publishes the affected capability.
